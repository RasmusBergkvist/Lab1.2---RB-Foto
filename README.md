# Laborationsuppgift: Bildredigering
Detta är en laborationauppgift 1.2 i kursen DT200G Grafisk teknik för webb. Uppgiften gick ut på att redigera tre stycken bilder så att det känns att de tillhör samma grafiska profil.
Till uppgiften har även en hero-bild, logotyp och favicon tagits fram. Det har även frilagts en porträttbild.
